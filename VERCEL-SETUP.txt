LYPPE AI - VERCEL SETUP
========================

Environment Variable yang wajib:
Name: GEMINI_API_KEY
Value: API KEY GEMINI KAMU
Environment: Production (dan Preview/Development jika diperlukan)

Opsional:
GEMINI_MODEL=gemini-3.8-flash

PENTING: setelah mengubah Environment Variable, lakukan Redeploy.

Backend memakai model Gemini 3.8 Flash dan API key hanya dibaca server-side
dari process.env.GEMINI_API_KEY. Jangan taruh API key di index.html.
