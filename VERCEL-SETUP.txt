Lyppe AI - FAST / STABLE VERSION

1. Upload/replace the project files in GitHub.
2. Vercel must have this Environment Variable:
   GEMINI_API_KEY = your Google AI Studio API key
   Enable it for Production (and Preview if needed).
3. Redeploy Vercel after changing Environment Variables.

This version uses Gemini 3.8 Flash via the current Interactions API with streaming SSE and low thinking level for fast responses.
API key stays server-side and is never placed in index.html.

The frontend also supports image/video attachments and a fullscreen media viewer with an X button.
